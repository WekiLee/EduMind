# Contributing to EduMind

We welcome contributions! Here's how you can help.

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Commit your changes: `git commit -m "Add your feature"`
4. Push: `git push origin feature/your-feature`
5. Open a Pull Request

## Development Setup

See [docs/DEPLOYMENT_RECORD.md](docs/DEPLOYMENT_RECORD.md) for local development setup.

## Code Style

- **Python**: Follow PEP 8, run `ruff check .` before committing
- **TypeScript**: Follow project's ESLint configuration
- **Commits**: Use conventional commits (feat:, fix:, docs:, refactor:, etc.)

## Pull Request Guidelines

- Keep PRs focused on a single concern
- Add tests for new features
- Update documentation when changing behavior
- Ensure all existing tests pass

## Reporting Issues

- Use the GitHub issue tracker
- Include steps to reproduce for bug reports
- Mention your environment (OS, Python version, etc.)
